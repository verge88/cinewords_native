# CineWords Native

Нативная Android-версия [CineWords](https://github.com/verge88/cinewords) на **Kotlin + Jetpack Compose** (без Flutter runtime).

## Сборка

Нужны Android SDK Platform 35, JDK 17 и Gradle 8.10.2. Откройте репозиторий в Android Studio или выполните:

```bash
gradle :app:assembleDebug
gradle :app:testDebugUnitTest
```

В `local.properties` укажите путь к Android SDK и **свои** ключи, если нужны соответствующие каталоги:

```properties
sdk.dir=/path/to/Android/Sdk
YOUTUBE_API_KEY=...
KINOPOISK_API_KEY=...
```

Эти значения автоматически попадают в BuildConfig во время сборки. `local.properties` добавлен в `.gitignore`. Публичный Supabase URL и *publishable* key совпадают с Flutter-версией; данные аккаунта и словарь остаются в тех же таблицах.

## Реализовано

- Авторизация/регистрация через Supabase, хранение и обновление сессии, выход.
- Главная страница и каталог: избранное, поиск/пагинация YouTube Data API, видео из Supabase, поиск фильмов в Kinopoisk.
- Страница видео; воспроизведение YouTube через iframe/WebView и прямых HLS/MP4 через Media3 ExoPlayer, сторонние iframe для фильмов.
- EN/RU субтитры из Supabase, прямые SRT/VTT, синхронизация по позиции, транскрипт с переходом на таймкод, нажатие на слово для добавления в словарь.
- Словарь: фильтрация, поиск, слова и фразы, добавление, удаление, транскрипция/перевод, карточки SM-2 через существующий Supabase RPC.
- 11 вариантов в разделе упражнений (включая карточки, семантические кластеры, определения, shadowing, диктант, минимальные пары, конструктор, времена, cloze, читалку и невидимые слова). TTS — системный Android.
- Профиль, статистика, системная/светлая/тёмная/монохромная темы.

## Ограничения текущего переноса

Это **первый нативный порт**, а не подтверждённый 1:1 перенос всех внутренних алгоритмов Flutter-проекта. Сторонние источники видео (Rivestream/VDRK/Internet Archive/DDGS/SearXNG), автоматическое получение YouTube-транскриптов и автоперевод всех субтитров пока не обеспечены в полном объёме. Текущая реализация пытается прочитать YouTube timedtext, который доступен не для всех видео. Для фильмов открывается исходный embed-сервис, а не нативный поток Rivestream. Некоторые упражнения упрощены относительно Flutter-версии (например, shadowing без автоматического распознавания произношения).

Перед публикацией необходимы проверка Android-сборки и ручная проверка на устройстве: Supabase авторизация, обновление токена, поведение плеера, доступность EN/RU субтитров, корректность избранного и RPC SM-2, работа сетевых API. Доступность внешних провайдеров зависит от региона и их API. Не храните приватные API-ключи в репозитории.

## Архитектура

- `CineApi.kt` — модели, доступ к Supabase REST/Auth/RPC, YouTube, Kinopoisk, словарь и парсер субтитров.
- `CineState.kt` — общее состояние приложения и загрузка данных.
- `MainActivity.kt` — приложение, темы и навигация.
- `Screens.kt` — каталог, профиль, словарь и SRS.
- `PlayerScreen.kt` — видео и синхронизированные субтитры.
- `Exercises.kt` — тренажёры.

Реализация рассчитана на Android 7.0+ (API 24), minSdk 24.
